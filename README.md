hitalent_task_test

Тестовое задание: 
API-сервис бронирования столиков в ресторане 

Цель: 
Разработать REST API для бронирования столиков в ресторане.
Сервис должен позволять создавать, просматривать и удалять брони, а также управлять столиками и временными слотами.

Стек технологий

- **FastAPI** 
- **PostgreSQL** 
- **SQLAlchemy**
- **Docker и Docker Compose**

Убедитесь, что у вас установлены следующие программные компоненты:

- [Docker](https://www.docker.com/products/docker-desktop)
- [Docker Compose](https://docs.docker.com/compose/install/)

1. Клонируйте репозиторий на ваш локальный компьютер:
 
   bash 
    - git clone https://github.com/Neymand/hitalent_task_test.git cd your-repository

2. Соберите и запустите контейнеры Docker с помощью команды:
   
    bash
    - docker-compose up --build
   
   
4. После запуска контейнеров приложение будет доступно по адресу 
    - [http://localhost:8000](http://localhost:8000)
